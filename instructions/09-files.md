# Файлы

## Для чего нужен раздел файлов

Раздел файлов - это внутреннее хранилище документов и рабочих материалов. Он помогает держать файлы в единой структуре, а не хранить их в разрозненных папках на компьютерах сотрудников.

Раздел особенно полезен для совместной работы: файлы можно загрузить в систему, разложить по папкам, быстро найти, открыть, скачать или переместить.

Скриншот: файловый раздел с папками, каталогом и режимами отображения.

## Что можно делать в разделе

- создавать папки;
- загружать файлы;
- просматривать каталог в виде сетки или списка;
- искать файлы по названию;
- фильтровать по категориям;
- открывать и скачивать файлы;
- перемещать файлы по папкам;
- удалять файлы и папки при наличии прав.

## Как устроен интерфейс

Обычно экран состоит из нескольких частей:

- верхняя панель со статистикой и действиями;
- фильтры поиска и категории;
- хлебные крошки для навигации по папкам;
- левая панель с быстрым доступом и деревом папок;
- основная область с каталогом файлов.

## Как загрузить файл

1. Откройте нужную папку или оставайтесь в корне.
2. Нажмите `Загрузить`.
3. Выберите файл на компьютере.
4. Дождитесь завершения загрузки.
5. Проверьте, что файл появился в каталоге.

Если заранее открыть правильную папку, потом не придется переносить файл вручную.

Скриншот: кнопка загрузки файла и список загруженных документов.

## Как создать папку

1. Нажмите `Новая папка`.
2. Укажите понятное название.
3. Сохраните папку.
4. При необходимости откройте ее и загрузите туда файлы.

Лучше заранее договориться о логике наименований, например по клиентам, проектам, отделам или типам документов.

## Режимы просмотра

### Сетка

Удобна для визуального просмотра, особенно если в папке много изображений или нужно быстро ориентироваться по типам файлов.

### Список

Удобен, когда важны дата, размер, расширение и точные названия документов.

Пользователь может переключаться между этими режимами в зависимости от задачи.

## Поиск и фильтры

В разделе доступны:

- поиск по названию файла или документа;
- фильтр по категориям: все файлы, изображения, документы, архивы.

Это особенно полезно, когда хранилище уже большое и ручной просмотр папок занимает слишком много времени.

## Работа с папками и структурой

Для порядка рекомендуется использовать понятную структуру. Например:

- отдельные папки по клиентам;
- отдельные папки по проектам;
- отдельные папки для шаблонов, отчетов, договоров и медиа.

Если структура продумана заранее, новым сотрудникам гораздо проще находить нужные материалы.

## Открытие, скачивание и перемещение

Пользователь может:

- открыть файл для просмотра;
- скачать файл;
- переместить его в другую папку;
- переименовать папку;
- удалить объект при наличии прав.

При групповой работе лучше сначала договориться, кто отвечает за структуру и чистоту хранилища, чтобы файлы не дублировались и не терялись.

Скриншот: контекстное меню файла или папки.

## Практические рекомендации

1. Не загружайте один и тот же файл несколько раз без необходимости.
2. Называйте файлы так, чтобы по имени было понятно содержание.
3. Складывайте документы сразу в нужные папки.
4. Для регулярных процессов используйте единый шаблон структуры.
5. Если файл относится к клиенту или проекту, храните его рядом с соответствующей папкой, а не в случайном месте.

## Типичные ошибки

- файлы загружаются в корень без структуры;
- названия документов непонятны;
- сотрудники дублируют один и тот же файл в разных местах;
- важные файлы удаляются без согласования;
- папки создаются хаотично и быстро превращаются в беспорядок.

## Когда файловый раздел особенно полезен

Он особенно полезен, если компания работает с большим количеством договоров, счетов, коммерческих предложений, актов, презентаций, изображений и внутренних документов, которыми пользуются несколько сотрудников одновременно.
