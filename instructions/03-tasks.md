# Задачи

## Для чего нужен раздел задач

Раздел задач помогает планировать и контролировать работу команды. Через него удобно ставить поручения, отслеживать статус выполнения, назначать ответственных и видеть загрузку по проектам и отделам.

Система поддерживает несколько способов просмотра задач, поэтому каждый пользователь может выбрать наиболее удобный формат: список, канбан, диаграмму Ганта или календарь.

Скриншот: раздел задач с переключением между режимами просмотра.

## Что можно делать в разделе задач

- создавать новые задачи;
- назначать исполнителей;
- указывать проект и отдел;
- задавать статус и приоритет;
- отслеживать просроченные задачи;
- открывать связанные документы;
- видеть связь задачи с клиентом или сделкой из CRM.

## Как создать задачу

1. Откройте раздел `Задачи`.
2. Нажмите `Создать задачу`.
3. Заполните название и описание.
4. Укажите проект, отдел, исполнителя и срок.
5. Выберите приоритет.
6. Сохраните задачу.

Если задача относится к клиенту или сделке, по возможности укажите эту связь сразу. Тогда она будет видна и в CRM-контексте.

## Какие режимы просмотра есть в системе

### Список

Подходит для повседневной работы, когда нужно быстро найти задачу, отсортировать список и просмотреть много задач подряд.

### Канбан

Удобен для визуального контроля статусов. Пользователь видит колонки по этапам и может быстро понять, где скапливаются задачи и какие зависли.

### Диаграмма Ганта

Полезна руководителям и координаторам, когда нужно видеть сроки, параллельные работы и пересечения по времени.

### Календарь

Подходит, если важна привязка к датам и нужно видеть загрузку команды по дням.

Скриншот: один и тот же набор задач в списке, канбане и календаре.

## Как использовать фильтры

В разделе доступны фильтры по:

- проекту;
- статусу;
- отделу.

Это позволяет быстро отделить свои задачи от общего массива или найти блок задач по конкретному направлению работы.

Рекомендуется сначала выбрать проект или отдел, а затем уже анализировать статусы и сроки.

## Приоритеты и сроки

При постановке задачи важно правильно выбирать приоритет. Если все задачи создаются как срочные, приоритет перестает быть полезным инструментом. Лучше придерживаться простого правила:

- обычный приоритет - стандартная рабочая задача;
- высокий - задача требует повышенного внимания;
- срочный - задача влияет на клиента, деньги или критичный процесс и должна быть выполнена в первую очередь.

Просроченные задачи желательно обрабатывать ежедневно: либо переносить срок с понятным комментарием, либо доводить задачу до результата.

## Как контролировать выполнение

Для контроля рекомендуется смотреть:

- общее количество задач;
- число просроченных;
- задачи с высоким приоритетом;
- задачи без исполнителя.

Эти показатели позволяют быстро увидеть слабые места в работе команды.

## Связь задач с CRM и документами

Задача может быть связана с:

- клиентом;
- сделкой;
- документами.

Это особенно удобно для коммерческих и сервисных процессов. Например, менеджер ставит задачу подготовить договор по клиенту, а исполнитель открывает документы прямо из карточки задачи.

## Практические рекомендации

1. Название задачи делайте понятным и конкретным.
2. В описании сразу пишите ожидаемый результат, а не только действие.
3. Обязательно указывайте ответственного.
4. Не держите задачу без статуса и без срока, если для нее важен контроль.
5. Если задача изменилась по объему, лучше обновить описание и комментарии, чем создавать новую без причины.

## Типичные ошибки

- задача создана без исполнителя;
- срок не указан;
- описание слишком короткое и непонятно, что нужно сделать;
- задача есть в системе, но фактически договоренности ведутся в чате и не отражаются в карточке;
- просроченные задачи просто копятся без пересмотра.

## Как выстроить ежедневную работу

Исполнителю полезно начинать день с просмотра:

1. срочных задач;
2. просроченных задач;
3. задач на сегодня;
4. уведомлений по изменениям.

Руководителю полезно регулярно открывать канбан, чтобы видеть узкие места по статусам, а также проверять задачи без исполнителя и задачи с критичными сроками.
