# Виджеты сайта

## Для чего нужен раздел виджетов

Раздел `Виджеты сайта` используется для настройки публичных форм и элементов связи, которые размещаются на внешнем сайте компании. Через этот раздел можно подготовить код вставки, настроить тексты, брендирование и выбрать сценарий показа.

Это важно для компаний, которые принимают обращения с сайта и хотят, чтобы они попадали в рабочую систему в управляемом виде.

Скриншот: раздел виджетов сайта с настройками профиля и кодом вставки.

## Какие сценарии поддерживаются

В интерфейсе предусмотрены два основных сценария:

- плавающая кнопка с чатом;
- встроенная форма на странице.

### Плавающая кнопка

Подходит для большинства сайтов. Пользователь сайта видит компактную кнопку, открывает окно и может начать общение или оставить обращение.

### Встроенная форма

Подходит для страниц, где уже есть отдельный блок для заявки и нужен более статичный способ сбора обращений.

## Что такое профиль виджета

Профиль нужен для управления отдельным сайтом, брендом или вариантом публикации. Если у компании несколько сайтов или лендингов, можно создать несколько профилей и хранить настройки отдельно.

Профиль обычно включает:

- название;
- slug;
- активность;
- параметры публикации;
- тексты интерфейса;
- цвет и брендирование;
- код вставки.

Скриншот: список профилей виджета и кнопка создания нового профиля.

## Как создать и настроить профиль

1. Откройте раздел `Виджеты сайта`.
2. Создайте новый профиль.
3. Укажите понятное название.
4. При необходимости задайте slug.
5. Откройте профиль для редактирования.
6. Настройте API base, тексты, цвета и нужный сценарий.
7. Сделайте профиль активным, если он должен использоваться по умолчанию.

## Основные настройки, на которые нужно обратить внимание

### API base

Это адрес, по которому виджет будет взаимодействовать с системой. Его нужно указывать внимательно, иначе заявки и сообщения не будут работать корректно.

### Положение кнопки

Можно выбрать расположение справа или слева. Эта настройка касается плавающей кнопки.

### Тексты интерфейса

Виджет позволяет настроить:

- текст на кнопке;
- подпись;
- короткое описание;
- заголовок окна;
- короткий статус;
- заголовок и описание формы.

Эти тексты лучше делать понятными и короткими. Пользователь сайта должен быстро понять, зачем нажимать кнопку и что произойдет дальше.

### Цвет и брендирование

Можно задать основной цвет и базовые элементы бренда. Желательно выбирать цвет, который хорошо сочетается с сайтом и не выглядит случайным.

## Как получить код вставки

После настройки профиля система показывает готовый код для вставки. Обычно пользователь выбирает нужный вариант:

- код для плавающего виджета;
- код для встроенной формы.

Далее этот код передают разработчику сайта или специалисту, который отвечает за публикацию.

Скриншот: блок с готовым кодом вставки виджета.

## Как понять, что виджет настроен правильно

После публикации проверьте:

1. Виджет отображается на сайте.
2. Кнопка открывается без ошибок.
3. Тексты выглядят корректно.
4. Цвета соответствуют ожиданиям.
5. Тестовое обращение доходит в систему.
6. Новая заявка появляется у сотрудников в нужном разделе.

## Практические рекомендации

- Делайте отдельные профили для разных сайтов и посадочных страниц.
- Перед публикацией всегда отправляйте тестовую заявку.
- Не используйте слишком длинные тексты в кнопке или форме.
- Если виджет стоит на нескольких сайтах, храните понятные названия профилей, чтобы их не путать.
- Сначала согласуйте тексты и цвет с маркетингом или ответственным за сайт, а потом публикуйте изменения.

## Типичные ошибки

- неверно указан API base;
- опубликован не тот профиль;
- текст слишком длинный и ломает интерфейс;
- после настройки не была проведена тестовая заявка;
- профиль создан, но не сделан активным.
