# Документы

## Для чего нужен раздел документов

Раздел документов предназначен для хранения шаблонов и быстрой генерации файлов по данным клиента из CRM. Это позволяет не собирать договоры и коммерческие предложения вручную каждый раз, а использовать заготовленные шаблоны с автоподстановкой реквизитов.

Скриншот: раздел документов со списком шаблонов и блоком генерации.

## Что можно делать в разделе

- создавать шаблоны документов;
- загружать HTML-шаблоны;
- использовать DOCX-шаблоны из папки `docs/`;
- выбирать клиента CRM для подстановки данных;
- генерировать один документ;
- собирать пакет из нескольких документов;
- скачивать результат отдельно или архивом.

## Какие шаблоны поддерживаются

В системе используются два основных подхода:

- HTML-шаблоны - удобны для гибкой разметки и быстрого редактирования;
- DOCX-шаблоны - подходят, если компания работает с документами Word и нужно сохранить привычный формат.

Если документ должен активно редактироваться внутри системы, часто удобнее HTML. Если нужен официальный файл для передачи клиенту в Word-формате, обычно используют DOCX.

## Как создать новый шаблон

1. Откройте раздел `Документы`.
2. Нажмите `Новый шаблон`.
3. Укажите название и описание шаблона.
4. Выберите формат.
5. Добавьте переменные, которые должны подставляться из CRM.
6. Сохраните шаблон.

Также можно загрузить готовый HTML-файл через кнопку `Загрузить HTML`.

Скриншот: создание нового шаблона документа.

## Как сгенерировать документ по клиенту

1. Выберите шаблон в списке слева.
2. В блоке `Генерация` выберите клиента CRM.
3. Проверьте, что в карточке клиента заполнены нужные данные.
4. Нажмите `Сгенерировать 1 документ`.
5. Скачайте готовый результат.

Если нужно сразу несколько файлов, отметьте шаблоны галочками и используйте генерацию пакета.

## Как работает генерация пакета

Пакет полезен, когда по одному клиенту нужно подготовить сразу несколько документов, например:

- договор;
- приложение;
- счет;
- коммерческое предложение;
- карточку клиента.

Пользователь отмечает нужные шаблоны, выбирает клиента и запускает генерацию. После этого система формирует комплект файлов для скачивания.

## Переменные и автоподстановка

В интерфейсе есть список поддерживаемых переменных. Обычно это поля вида:

- данные клиента;
- данные компании;
- банковские реквизиты;
- данные подписанта;
- системные даты.

Важно понимать: если поле пустое в CRM, то и в документе оно может остаться пустым или подставиться некорректно. Поэтому перед генерацией стоит проверить карточку клиента.

Скриншот: список токенов или переменных для шаблонов.

## Особенности DOCX-шаблонов

Для DOCX-шаблонов лучше использовать простые токены без сложной структуры. На практике это означает:

- ставить токен как единый текстовый фрагмент;
- не разбивать токен сложным форматированием внутри Word;
- по возможности избегать нестандартных объектов и сложных полей.

Если шаблон ведет себя нестабильно, сначала проверьте его на простом тестовом клиенте с полностью заполненной карточкой.

## Когда документы удобно открывать не из общего раздела

В системе документы могут открываться и из других контекстов, например:

- из карточки клиента;
- из задачи.

Это удобно, когда сотрудник работает не с архивом шаблонов, а с конкретной рабочей ситуацией.

## Рекомендации по организации шаблонов

1. Используйте понятные названия шаблонов.
2. Добавляйте описание, чтобы сотрудники понимали назначение документа.
3. Разделяйте шаблоны по категориям: договоры, коммерческие предложения, внутренние формы и так далее.
4. После изменения шаблона проверяйте генерацию на тестовом клиенте.
5. Не храните в одном шаблоне слишком много логики, если это усложняет поддержку.

## Частые проблемы и что проверять

### В документ не подставились данные

Проверьте, заполнены ли соответствующие поля в карточке клиента и правильно ли указан токен в шаблоне.

### Не формируется пакет документов

Проверьте, выбран ли клиент и отмечены ли шаблоны для пакета.

### DOCX выглядит странно после генерации

Чаще всего причина в сложной структуре шаблона Word. Упростите токены и повторите тест.

## Для кого особенно полезен раздел

Раздел документов особенно важен для менеджеров продаж, бухгалтерии, руководителей и сотрудников, которые регулярно готовят типовые документы по одним и тем же правилам.
