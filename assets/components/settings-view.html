WooCommerce Referral integration
Настройка CRM для плагина WorkHub Woo Referrals: URL магазина, общий секрет и готовые endpoint'ы для вставки в WooCommerce.
Базовый адрес магазина, куда CRM будет вести по referral-ссылкам. Пример: https://shop.example.com/
CRM сначала использует secret из настроек, а если он не сохранён - fallback на legacy `REFERRAL_SHARED_SECRET` из config/env. Пустое поле не перезаписывает текущий secret.
Ключ хранится в настройках и скрыт в поле ввода. Оставьте пустым, чтобы не менять текущий ключ.
Пустое поле не перезаписывает текущий секрет. Используется только для API-импорта истории заказов.
Что вставить в WooCommerce-плагин
  1. В поле CRM webhook URL вставьте Order webhook endpoint.
  2. В поле Shared secret укажите тот же secret, который сохранён в CRM.
  3. Если в плагине включён tracking визитов, используйте Visit endpoint.
  4. После сохранения запустите connection test в WooCommerce-плагине.
