Нет доступных клиентов CRM
Для автоподстановки данных и генерации документов нужен хотя бы один клиент.
Сначала выберите клиента
После выбора клиента система покажет доступные данные для подстановки и историю генераций.
1. Выбор
Отметьте галочками шаблоны, которые должны войти в пакет.
2. Генерация
HTML-шаблоны рендерятся полностью. DOCX из docs/ поддерживают простые токены вроде {{company.full_name}} и {{bank.bik}}, а также часть токенов, разбитых Word на соседние текстовые run-узлы внутри одного абзаца.
3. Выгрузка
Готовые HTML и DOCX-файлы можно скачать отдельно или одним пакетом.
Поддерживаемые переменные
Нажмите на токен, чтобы скопировать его в формате {{token}}. Для DOCX в первую очередь используйте простые текстовые поля клиента, компании, банка, подписанта и системные даты.
Данные клиента
Контекст подстановки для выбранного клиента и шаблона.

                    

                


                

                    

                        

                        

                        

                            
                        

                    

                            

                                
Рекомендации для DOCX

                                
Используйте простую структуру токенов для корректной подстановки в Word.

                                
    
                                    
  • Используйте простые токены вида {{client.name}}, {{company.full_name}}, {{bank.checking_account}}.
    • 
                                    
  • Лучше использовать цельный токен внутри одного текстового блока.
    • 
                                    
  • Сложная разметка Word, поля, фигуры и нестандартные таблицы могут мешать подстановке.
    • 
                                    
  • HTML-блоки вроде {{tasks.table}} и JSON-поля лучше использовать в HTML-шаблонах.
    • 
                                    
  • На этом сервере `ZipArchive` недоступен, поэтому DOCX будут сохраняться без внутренней замены токенов.
    •

Источник: 

                        
Поддерживается подстановка простых текстовых токенов в DOCX-шаблонах.

                        

                        
    
                            
                        

                    

                    

                        Для HTML используйте переменные вида {{client.name}}, {{tasks.table}}, {{system.generated_at}}. Для DOCX используйте простые токены {{client.*}}, {{company.*}}, {{bank.*}}, {{system.*}} в тексте Word-шаблона.
